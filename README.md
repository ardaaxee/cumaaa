## ❤️ love-heart

Sevgiliye gönderilebilecek, tek büyük animasyonlu kalpten oluşan minimal
Flask sitesi. Kalbe dokununca kalp güçlüce atar ve küçük kalpler yayılır.

Proje klasörü: [`love-heart/`](love-heart/)
Kurulum, kişiselleştirme ve ücretsiz deployment adımları:
[`love-heart/README.md`](love-heart/README.md)

Hızlı başlangıç:

```bash
cd love-heart
pip install -r requirements.txt
python3 app.py     # http://127.0.0.1:5000
```
